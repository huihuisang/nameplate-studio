# 姓名卡片生成器

一个完全在本地运行的网页工具，不会上传姓名或图片。默认生成 2362 × 2362（300 DPI，20 × 20 cm）的桌面铭牌 PNG：下半区为正面，上半区由下半区旋转 180° 自动生成，方便桌子对面的人阅读。

## 使用方法

1. 双击 `index.html` 在浏览器中打开即可（推荐 Chrome / Edge）。
2. 在模板条选择模板；点击图层 chip（如「姓名」「编号」）后在检查器的「文字」字段输入内容，画布上拖动调整位置、拖动边角缩放。
3. 在预览区可选择编辑区比例预设（2:1 / 8:3 / 4:1）或自定义宽高，画布容器按比例自适应大小。
4. 点击左下角「下载 PNG」导出。

底图已内置于页面中，双击打开即可正常下载，无需启动本地服务。

> 可选：双击 `start.command` 会启动本机服务并在 Chrome 打开 `http://localhost:4173`。只有「加载系统字体」功能依赖 localhost 环境（浏览器安全限制）。若 macOS 首次阻止脚本运行，可在终端执行 `./start.command`。

## 界面说明

- **内容**：直接编辑姓名和编号，对应画布上的两个默认图层。
- **图层**：点击 chip 切换图层；选中后可在下方检查器中调整字体、字号、颜色和阴影。`＋文本` `＋图片` 可添加自定义图层。
- **位置**：在画布上拖动图层即可；选中后也可用方向键微调（Shift + 方向键为 1px 步进），Delete/退格键删除选中的自定义图层。
- **批量导出**：见下文。

## 批量导出

1. 展开「批量导出」，导入 CSV、TSV、XLS 或 XLSX 文件。
2. 第一行会视为表头，工具会自动匹配姓名、编号列；不准确时在下拉菜单中手动选择。
3. 点击「下载 ZIP」，每条记录都会生成一张 2362 × 2362 PNG，合并成一个 ZIP 下载。

建议将编号列在 Excel 中设置为“文本”或使用显示格式，例如 `07`。导入会读取单元格显示内容，因此会保留这类前导零。

## 字体

- 中文姓名：ZCOOL KuaiLe（站酷快乐体）。
- 数字：Anton Regular。

点击检查器中的「字体」会打开字体选择弹窗：左侧为字体名称，右侧用当前姓名实时预览效果，顶部可搜索过滤（分组为内置字体 / 上传的字体 / 系统字体）。底部可「上传字体文件」使用单独的字体（.ttf / .otf / .woff / .woff2），或「加载系统字体」列出本机全部字体（仅 localhost 模式）。字体清单和姓名数据都只在本机浏览器中处理。

## 文件说明

- `index.html`：页面结构。
- `styles.css`：界面样式与字体声明。
- `app.js`：Canvas 绘制、图层编辑、国际化、表格导入与 PNG / ZIP 导出。
- `template-data.js`：由 `assets/template-clean.png` 生成的 base64 内联底图，避免 `file://` 打开时画布被污染导致无法导出。重新生成底图后执行：
  ```bash
  { printf "window.TEMPLATE_DATA_URI = 'data:image/png;base64,%s';\n" "$(base64 -i assets/template-clean.png | tr -d '\n')" > template-data.js; }
  ```
- `assets/template-clean.png`：清除原姓名及编号后的底图（`template-data.js` 的来源）。
- `vendor`：离线表格读取和 ZIP 打包依赖（SheetJS 与 JSZip）。
